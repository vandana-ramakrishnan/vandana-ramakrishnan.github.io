## Publishing
Create or open the public GitHub Pages repository `vandana-ramakrishnan.github.io`. Upload the *contents* of the `GitHub-ready` ZIP so `index.html`, `assets/` and `styles.css` are at repository root. Under Settings → Pages choose Deploy from branch, `main`, `/(root)`.

The GitHub-ready ZIP deliberately omits manuscript PDFs, since putting a PDF in a public GitHub repository exposes it even if no link is visible on the website. A separate working-copy ZIP contains the original PDFs.

The CV Google Drive sharing setting should be `Anyone with the link` / `Viewer`; verify access in a private browsing window.
